# SpectrumIQ requirements

These requirements come from [goals.md](goals.md) and from the planning decisions of 2026-10-23 (see
[plan/README.md §2](plan/README.md#2-decisions-from-planning)).

- **IDs are stable.** Never renumber an ID. Retire one by striking it through and noting why.
- **"Verified by"** is filled in by each phase with test names, and later generated by
  `cargo xtask trace`.
- **Source codes:**
  - `G` = goals.md;
  - `Q` = the planning Q&A;
  - `D` = derived from the architecture.
