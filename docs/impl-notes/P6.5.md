## Summary

- **The `workflow` Thing** (ADR-0056):
  - **runs:** `run` for any plan; `tile_scan` (after a `focus_map` if given), `z_stack`,
    `multi_position` (the saved positions if none) and `time_lapse`, each with its step's
    fields. Each holds the global lock until its run ends, and answers with how it ended;
  - **422 for a plan that couldn't run:** each input is checked by the engine's `Plan::check` as
    it deserializes. One this instrument can't run fails its invocation at once;
  - **cancelling** is a `DELETE` of the invocation; `pause` and `resume` don't take the lock;
  - **observed:** `state` and `progress`; `tile_acquired` and `finished`. `plan_schema` has a
    plan's JSON Schema, which a TD can't hold.
- **Saved positions,** in `positions.json` in the settings folder: `save_position` (where the
  stage and focus are, unless given), `rename_position`, `remove_position`, and `positions`.
- **`DatasetHook::on_dataset_complete`:** the instrument's hooks are told of each run's dataset,
  for M8's stitching.
- **The engine:** `Plan::check`, its checks that need no instrument, apart from the run's; a
  time-lapse with no steps takes a frame.
- **The simulator's sample in focus at 2000 µm** of the focus drive's travel (`[sim] focus_at`),
  where the drive starts: `DialectEmulator::in_focus_at`. `sim_rig` focuses about it.
- **Scripts:** `examples/python/tile_scan.py`, `z_stack.py` and `timelapse.py`; `test.http`'s
  workflow requests.

## Deviations

1. **A plan that this instrument can't run fails its invocation, not with 422:** its channels
   and calibration are known only to the instrument, which the input's deserializing hasn't.
   Every check that needs no instrument is a 422.
2. **`steps` are opaque in the TD:** teta-wot inlines every schema reference, and a plan's steps
   nest. `plan_schema` describes them.
3. **Saved positions in a file of their own,** not a teta-wot `#[setting]`: that needs teta-wot's
   settings folder, which would also persist every other Thing's settings.
4. **`run`, beyond the brief's named actions:** for compositions, as the UI builds them.
5. **The simulator's focal plane moved,** from P6.3's follow-up: in focus at the bottom of the
   drive's travel, an autofocus or a z-stack there would have left it.
