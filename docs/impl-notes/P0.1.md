# P0.1 — Workspace, toolchain, xtask and templates — implementation notes

- **Status:** Review
- **Branch / commits:** `phase/P0.1-workspace`, from `main` at `0338d80`
- **Date:** 2026-10-23

## Summary

- **The workspace.** The single `SpectrumIQ` binary crate became a virtual Cargo workspace with:
  - members `crates/*`, `apps/*` and `xtask`;
  - shared package metadata, dependency versions and lints;
  - `teta-wot` declared as a git dependency at tag `v0.1.0`.
- **Toolchain and formatting:** pinned to 1.99.1 (`rust-toolchain.toml`), `style_edition = "2024"`,
  and LF line endings (`.gitattributes`).
- **`cargo xtask`** has three tasks:
  - `ci`: the quality gate;
  - `loc`: the code budget, including import-commit exclusion;
  - `layers`: the crate layering, with the full crate table of architecture §3.1.
- **Templates** for implementation notes and crate READMEs, plus READMEs for `crates/`, `apps/`,
  `xtask/` and the repository.
- **`deny.toml`** holds the licence policy for cargo-deny.

## Interfaces

Later phases rely on these:

- **Commands:**
  - `cargo xtask ci [--skip-web] [--e2e]`, which exits non-zero at the first failing step;
  - `cargo xtask loc [--base main] [--budget 1000] [--files]`, which exits 1 when the counted lines
    reach the budget;
  - `cargo xtask layers`, which exits 1 on any violation.
- **`xtask` library:**
  - `loc::{classify, Class, LineCounter, Report, Tally, measure, is_import_subject}`;
  - `layers::{TABLE, Layer, Violation, check, layer_of, TETA_WOT_USER}`;
  - `metadata::{Metadata, Package, Dependency, Target}`.
- **Rules for new crates:**
  - every new crate adds itself to `xtask/src/layers.rs` `TABLE`; `layers` fails otherwise;
  - every crate uses `[lints] workspace = true` and `*.workspace = true` package fields;
  - shared versions go in root `[workspace.dependencies]`.
- **Examples** run in `ci` with `SIQ_SMOKE=1`. Examples with `required-features` are skipped.
- **The import-commit marker** for copied code (P3.1) is the subject `chore(P<m>.<n>): import …`.
  `loc` counts the files such a commit adds only from that commit on.

## Deviations

1. **No uncommitted changes to show.** The brief asked to show the uncommitted `.gitignore`,
   `src/main.rs` and `Cargo.lock` changes before replacing anything. By the time the phase started,
   the owner had committed them in `0338d80`, and `src/main.rs` was the stock hello-world. It was
   removed.
2. **`crates/README.md` and `apps/README.md`** were added because Cargo refuses a member glob over
   a missing folder. Cargo ignores glob matches that aren't folders.
3. **`ci` also runs `cargo doc` with `-D warnings`,** beyond the conventions' list. Conventions §1.3
   and ADR-0017 are updated.
4. **The frontend example path is `web/src/views/dev/`,** where `microscope` keeps its dev
   galleries. Conventions said `web/src/dev/`, and §2, §6 and the ADR-0015 amendment are
   corrected.
5. **Architecture §3.1's "May depend on" column** said, for example, "L0: external crates only".
   That contradicted real needs: `siq-config` uses `siq-types`, and `siq-grbl` uses `siq-serial`.
   It now says "own layer and below", which is what `layers` enforces. `siq-mfenc` and `siq-shm` are
   added to L1.
6. **The estimate was about 600 lines; the phase measured 810.** rustfmt's one-item-per-line
   layout of arrays and argument lists accounts for much of the difference.
7. **`deny.toml` was added.** The brief didn't list it, but without it cargo-deny would reject every
   licence. It is unverified, because cargo-deny isn't installed (see Open questions).
8. **The `uuid` workspace dependency adds `v7`,** which P0.2 needs for `DatasetId`.

**`cargo xtask ci`** takes 9 s on a warm build. The first run also downloads the toolchain and
compiles every dependency.

**Dependency age.** Cargo first resolved five versions published less than two weeks earlier (after
2026-10-09). Each was downgraded to the newest older release:

| Crate | Resolved | Pinned to |
|---|---|---|
| `equivalent` | 1.0.3 | 1.0.2 |
| `libc` | 0.2.191 | 0.2.190 |
| `serde_json` | 1.0.154 | 1.0.151 |
| `syn` | 3.0.9 | 3.0.6 |
| `unicode-ident` | 1.0.27 | 1.0.26 |

Every other resolved version equals the one in teta-wot's lockfile, which predates 2026-10-03.

**Licences.** cargo-deny isn't installed, so the licence check was done by hand from
`cargo metadata`. All 38 Windows packages are MIT, Apache-2.0 OR MIT, Unlicense OR MIT, or
`(MIT OR Apache-2.0) AND Unicode-3.0`. All are in `deny.toml`'s allow-list.
