## Deviations

1. **No PrimeVue.** The brief's wrapper reimplementation, PT preset and ESLint retargeting don't
   apply.
   - Why: PrimeVue 5's licence is commercial or eligibility-limited, needs a key, and restricts
     redistribution.
   - Decision: the owner chose to keep `reka-ui` (ADR-0008, amended). Data tables (M9) will use
     TanStack Table, and trees Reka UI's `Tree`.
   - The brief's wrapper tests are the copied ones, which pass unchanged.
2. **More config files than the brief named** were imported: `index.html`, `env.d.ts`,
   `.gitignore` and `.prettierignore`. The build needs them.
3. **The lockfile is `microscope`'s,** trimmed by npm to this `package.json`. The installed versions
   are therefore the ones its tests ran on. `npm install --before=2026-10-10` kept every package
   older than the two-week rule.
4. **Licences** outside conventions §7's list, recorded in ADR-0028's amendment:
   - 0BSD (`tslib`, unbundled);
   - BlueOak-1.0.0 (development tools);
   - MPL-2.0 `lightningcss`, used unmodified at build time.
5. **`spectrumiq-server --port`,** beyond the brief, for the Playwright configuration that M9's
   end-to-end tests will use.
