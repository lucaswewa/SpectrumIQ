# P9.2 — Authorization layer and Hardware Control Token — implementation notes

- **Status:** Done (merged to `main` as `5d96753`)

- **Date:** 2026-10-27

## Summary

- **`siq-server::authz`** (ADR-0066): every route's class from its method and path (public, read,
  stop, processing, control, hardware, admin), and the decision for a caller, architecture §10's
  matrix. A change to a route without a class is refused.
- **The layer** (ADR-0065's) enforces it where `[auth] enforce` (on by default): 401 without a
  session, 403 with the reason for a role or a missing token. A request of the token's holder is
  its heartbeat.
- **`siq-auth::ControlManager`:**
  - the token requested (409, with its holder, while another holds it), released, or taken over
    by an admin or the local console;
  - lost after `control_timeout_s` (30) of the holder's silence;
  - let go at a logout;
  - nothing it started is stopped.
- **The `control` Thing:** `holder` and `since`, observed, and `changed` with the reason. It looks
  for a silent holder's timeout every second.
- **The routes:** `GET /api/siq/control`, and `POST /api/siq/control/request`, `release`,
  `heartbeat` and `take_over`; `me` says whether the session holds the token, and whether it is
  local.
- **The local console's login** (`siq-auth::LocalLogin`):
  - a one-time 256-bit secret in `local-login` in `[server] settings`, its file's access list
    the service's account alone, set with `SetNamedSecurityInfoW` before it holds anything;
  - `POST /api/siq/auth/local`, from a loopback address, opens a session as `[auth] local_user`,
    which may take the token over;
  - each secret works once.
- **`[auth]`** gains `enforce`, `control_timeout_s` and `local_user`; `config/sim.toml` sets
  `enforce = false` until P9.4.
- **`examples/python/two_clients.py`;** `test.http` gains the token's requests.

## Deviations

1. **The heartbeat is the holder's requests,** and an explicit heartbeat route, not teta-wot's
   WebSocket: the layer doesn't see the socket's messages, and a forgotten tab's socket would
   keep the token forever (ADR-0066).
2. **The token's operations are SpectrumIQ routes,** not the `control` Thing's actions: an action
   doesn't know its caller. The Thing observes.
3. **A seventh class, Control,** for the token's routes, beside the brief's five and the public
   ones.
4. **The display and the live mosaic's view take the token:** they are shared by every client.
5. **The local secret's file allows the service's account alone:** while the desktop starts the
   service they are the same account; a service run as another (M15) adds the interactive
   user's entry. The local login also accepts loopback addresses only.
6. **`config/sim.toml` doesn't enforce yet:** until P9.4's login page and the desktop's automatic
   login, enforcing would lock the web app out. The tests and `two_clients.py` enforce.
