# P1.1 — Frame pool (`siq-buffer`) — implementation notes

- **Status:** Done (merged to `main` as `f5a6acb`)
- **Branch / commits:** `phase/P1.1-frame-pool`, from `main` at `c8be1c8`
- **Date:** 2026-10-23

## Summary

- **`FramePool`:** N slots, allocated once. Each is whole 4 KiB pages, page-aligned and
  zero-filled. They come from `Backend::Heap`, or from `Backend::WindowsLocked`:
  - `VirtualAlloc`;
  - the minimum working set raised by the pool plus 64 MiB;
  - `VirtualLock`;
  - all of it undone when the pool is dropped.
- **The ownership protocol** (ADR-0021):
  - a slot is Free, Filling (exactly one `FillGuard`) or Leased (`FrameLease`s only);
  - `publish(meta)` consumes the guard, and checks that the image fits;
  - a clone is one atomic increment;
  - the last drop hands the slot, as a new guard, to the `ReleaseSink`. `ReturnToPool` is the
    default.
- **Views:** `image::<u8 or u16>()` and `as_bytes()` on leases; `image_mut`, `pixels_mut`,
  `bytes_mut` and `as_mut_ptr` (for DMA) on guards.
- **Metrics:** `<name>.free_slots`, `<name>.in_use_high_water`, `<name>.lease_ms`, plus `stats()`.
- **Unsafe** only in `alloc.rs` and `slot.rs`. Every block has a `SAFETY` comment, and the public
  API is safe.

## Interfaces

- **For P1.2, P1.7, P2.1 and P10.1:**
  - `FramePool::{new, try_acquire_free, take_all_free, set_release_sink, reset_release_sink,
    slots, slot_bytes, stats}`;
  - `PoolConfig`, `Backend`, `PoolError`, `PoolStats`;
  - `FillGuard::{slot, len, as_mut_ptr, bytes_mut, pixels_mut, image_mut, publish}`;
  - `FrameLease::{meta, slot, as_bytes, image, clone}`;
  - `ReleaseSink`, `ReturnToPool`, `Pixel` (u8, u16), `PublishError`, `PAGE`, `working_set`.
- **P1.7's simulated camera:** `try_acquire_free` → render through `image_mut` → `publish`.
  Default sink.
- **P10.1's Euresys driver:**
  - announce `take_all_free()` guards through `as_mut_ptr`, and keep each guard while its buffer is
    queued;
  - on `pop`, `publish` the buffer's guard;
  - install a sink that requeues released guards, and is cheap: it may hand them to the
    acquisition thread;
  - `reset_release_sink` when it stops.

## Deviations

1. **`slot_ptrs()` became `take_all_free()`,** returning guards that expose `as_mut_ptr()`. A pointer
   to announce always comes with ownership of the slot.
2. **`publish(slot, meta)` became `FillGuard::publish(meta)`,** which also checks that the image
   fits. On failure it gives the guard back in a `PublishError`.
3. **`ReleaseSink::release` takes a `FillGuard`,** not an index. The sink then owns what it may
   refill.
4. **"Ready" isn't a separate state.** It is the instant of publishing: the returned lease is the
   first reader.
5. **The API takes a `PoolConfig`, a `Clock` and an optional metrics `Registry`,** not the brief's
   `(slots, slot_bytes, backend)`. The pool needs a name for its metrics, and the shared clock for
   lease times.
6. **ADR-0007 is amended** so that test-only global allocators may use `unsafe`. The `no_alloc`
   test needs one.
