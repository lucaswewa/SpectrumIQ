# P0.2 — Domain types (`siq-types`) — implementation notes

- **Status:** Review
- **Branch / commits:** `phase/P0.2-domain-types`, from `main` at `a07cb63`
- **Date:** 2026-10-23

## Summary

- **Units:** `Micrometers`, `Millimeters`, `Nanometers`, `Millis` and `Hertz`, made by one macro.
  - Arithmetic, length conversions, `Millis` ↔ `Duration`, `Hertz` ↔ period.
  - `Display` with the symbol, honouring precision.
  - Serialized as bare numbers, with the unit in the JSON Schema description.
- **Geometry:** `Vec2Um`, `PointPx` (pixel centres at half-integers), `RectUm`, `RectPx` (with
  overflow-free edges and intersection), and `StagePose`.
- **Affine transforms:**
  - `Affine2`: `compose`, `invert`, `from_params`, `decompose`; serialized as two rows;
  - typed `StageToPixel` and `PixelToStage`, with `StageToPixel::for_frame` implementing the
    calibration convention of ADR-0018, ROI and binning included.
- **Imaging:**
  - `PixelFormat`, `Roi`, and `Binning` (`NonZeroU8`, so zero bins can't be deserialized);
  - `ImageView` and `ImageViewMut`: strided, never allocate, nested sub-views share memory,
    disjoint `rows_mut`;
  - `OwnedImage`, with 64-byte-aligned rows.
- **Frames:** `FrameMeta` is `Copy` with no heap data. It holds `FrameSeq`, `DeviceMicros`,
  `PoseQuality`, `FrameFlags`, and the channel, objective and calibration ids.
- **Ids:** `DatasetId` and `CalibrationId` (UUID v7), and `ChannelId` and `ObjectiveId` (configured
  `u16` numbers).
- **Time:** `Timestamp`, the `Clock` trait, `SystemClock` and `ManualClock`.

## Interfaces

Everything is re-exported at the crate root (`siq_types::FrameMeta`, …).

- **Contracts later phases rely on:**
  - `FrameMeta` stays `Copy` without heap data (REQ-ACQ-002's zero-allocation path);
  - `ImageView` and `ImageViewMut` are the pixel-access interface of every kernel;
  - `StageToPixel::for_frame` is the one implementation of the stage↔pixel convention;
  - `Arc<dyn Clock>` is how services share time.
- **The JSON forms** are pinned by insta snapshots in `crates/siq-types/tests/snapshots/`. The
  frame-metadata snapshot is the future JSON sidecar format (P4.1).
- **Changes after M1** need an ADR-0018 amendment (the brief's rule).

## Deviations

1. **`Clock::sleep_until` is deferred to P1.7.**
   - *What happened:* it was built here (with a `Condvar` in `ManualClock`, and tests), then
     removed to keep the phase under budget. It wasn't in the brief, and its first user is P1.7's
     render thread.
   - *Where it went:* P1.7's brief now lists it.
   - *The design to restore:*
     - `fn sleep_until(&self, deadline: Timestamp)` on the trait;
     - `SystemClock` calls `thread::sleep(deadline.saturating_since(now))`;
     - `ManualClock` adds `moved: Condvar`, `notify_all()` in `advance` and `set`, and
       `wait_while(guard, |now| *now < deadline)`.
   - *Tests to restore:*
     - a sleeper thread is not finished after a partial `advance`, and returns once the deadline
       is passed;
     - a past deadline returns at once.
2. **`serde_json` now has `float_roundtrip` workspace-wide.** The serde round-trip property tests
   found the default parser off by one ULP (`-94664258.14285716` → `…15`). Calibrations and poses
   in files must read back exactly. Recorded as an ADR-0006 amendment. The failing seeds are kept in
   `tests/serde.proptest-regressions`.
3. **`schemars` gains the `uuid1` feature,** so the uuid ids derive their schema (`format: uuid`).
4. **Over the estimate: 988 counted lines against about 800.**
   - The first complete version measured 1036.
   - The phase was brought under budget by:
     - deferring `sleep_until` (above);
     - dropping a `Default` derive nothing used (`FrameSeq`, `DeviceMicros`, `Timestamp`);
     - a shared private `Layout` for the views, which removed repeated struct literals and moved
       layout checks to one place;
     - shorter `bytes_per_pixel` and `Binning::new`.
   - Splitting adjacent `#[derive]`s doesn't help, because rustfmt merges them.
   - Style edition 2024 also wraps any attribute with more than 70 characters of arguments, which
     inflates long derive lists to 3 lines.
5. **Added beyond the brief, because the ADR and later phases need them:**
   - `StageToPixel` / `PixelToStage`;
   - `RectPx::intersection`;
   - `PointPx::pixel_centre`;
   - `FrameMeta::image_size`;
   - `FrameSeq::next`.

**A bug the refactor found:** a zero-width view with more than one row and a non-zero stride
panicked in `row()` over empty data. Indexing an empty range past the end still panics. It is now
fixed and tested (`a_view_without_columns_needs_no_data`).
